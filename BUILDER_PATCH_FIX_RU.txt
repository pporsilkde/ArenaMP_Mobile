ArenaMP Mobile Builder PatchFix V2
=================================

Исправление падения patch_disconnected из build log 89986446123.

Причина:
  patches/openmw/12-arenamp-magic-mali-stability.py ожидал старый
  byte-for-byte блок spellcasting.cpp без пустой строки перед "bool loop".
  В текущем AMP блок семантически тот же, но форматирование отличается,
  поэтому скрипт завершался:
    spellcasting.cpp hit VFX guard: expected exactly one anchor, found 0

Исправлено:
  * hit-VFX патч ищется по локальным C++ statement anchors, а не по
    точному многострочному тексту/пустым строкам;
  * аналогично укреплён animation.cpp VFX scene-instance block, который
    оказался следующим несовместимым whitespace-anchor;
  * скрипт остаётся идемпотентным: повторный запуск безопасен;
  * PATCHSET_ID поднят до v1.4, чтобы старый CI marker/cache не пропустил
    новую версию patch stage;
  * сохранены все исправления V1 для повторного/частично применённого patch state.

Проверено локально на реконструированном ArenaMP X017:
  06 -> 07 -> 08 -> 09 -> 10 -> 11 -> 12 проходит;
  повторный запуск 12 проходит;
  полный apply-arenamp-patches.sh проходит дважды.

Файлы архива накладывать поверх ArenaMP_Mobile builder с сохранением путей.
