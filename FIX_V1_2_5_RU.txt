ArenaMP Mobile Client V1.2.5

Исправление TES3MP Version mismatch:
- Android static resources теперь проверяются не только по BuildConfig.VERSION_CODE.
- Перед каждым запуском launcher сравнивает bundled assets/libopenmw/resources/version с установленным files/resources/version.
- Если commit hash/version отличается, resources и global config автоматически переустанавливаются.
- versionCode поднят 47 -> 48, поэтому первое обновление с V1.2.4 принудительно освежит resources/version.
- Пользовательский USER_CONFIG / сохранения / моды не удаляются.
- Новая иконка проекта и все V1.2.4 fixes сохранены.

Важно: сервер и клиент всё равно должны быть собраны от одного AMP commit. Этот fix устраняет stale Android resources/version; он не подделывает commit hash другого сервера.
