ArenaMP Mobile Client V1.2.7

Изменения:
- В игровом меню «Экран» скрыт список разрешений.
- Скрыты Fullscreen и Window Border; из кнопок оставлена только VSync.
- VSync перенесён в левую верхнюю область бывшего списка разрешений.
- Ползунки вкладки «Экран» скомпонованы без больших пустых промежутков.
- Android-скрытая Gamma исключена из визуального потока.
- В лаунчере удалена отдельная категория GUI / «Масштаб интерфейса».
- Launcher GUI scale теперь только автоматический; старый pref_uiScaling удаляется при запуске.
- Android versionCode возвращён на 47.
- Parent network identity V1.2.6 сохранена и не зависит от versionCode.
