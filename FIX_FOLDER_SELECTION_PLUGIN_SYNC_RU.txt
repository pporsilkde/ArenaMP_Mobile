ArenaMP Mobile — исправление импорта плагинов после выбора игровой папки
Date: 2026-08-17

Исправлено:
1) После выбора папки игра сразу импортирует порядок и состояние включения плагинов из build.ini.
   Раньше setupData() синхронизировал только IP/порт сервера, а ModsDatabase мог оставаться старым.
2) build.ini ищется без учета регистра имени: build.ini / Build.ini / BUILD.INI работают одинаково на Android.
3) Если build.ini еще нет, первичный порядок и включенные плагины берутся из [Game Files] Morrowind.ini.
   После импорта создается portable build.ini, чтобы следующий запуск был детерминированным.
4) Для BSA при первичном импорте сохраняются установленные Morrowind.bsa/Tribunal.bsa/Bloodmoon.bsa
   и добавляются архивы из [Archives] Morrowind.ini без дубликатов.
5) Исправление накопительное: сохраняет предыдущий fix порядка build.ini и server IP/CGNAT display logic.

Измененные файлы:
- app/src/main/java/ui/fragments/FragmentSettings.kt
- app/src/main/java/file/BuildManifest.kt
- app/src/main/java/file/GameInstaller.kt
