ArenaMP Mobile Client + Server V1.4.4

Изменения лаунчера:
- В главном окне над «Сервер ArenaMP» добавлен чекбокс «Запустить сервер».
  Галочка запускает/держит Android-сервер включённым, снятие останавливает его.
- При включённом локальном сервере строки IP/порт в главном окне показывают
  фактический локальный endpoint: 127.0.0.1, LAN-адрес устройства и порт из
  config/tes3mp-server.cfg. Эти поля блокируются от редактирования, чтобы
  локальный runtime не переписывал удалённый endpoint build.ini.
- complete=true продолжает блокировать только IP/порт build.ini. Состав,
  включение и порядок модов остаются редактируемыми и теперь сохраняются сразу.
- build.ini сохраняется после checkbox/drag изменений модов (debounce 200 мс)
  и принудительно при выходе из окна модов. При ошибке записи выводится сообщение.
- При complete=true любая случайная программная попытка изменить IP/порт
  откатывается обратно к значениям build.ini.

Сервер:
- Чекбокс на странице сервера синхронизирован с главным переключателем.
- Start/Stop синхронизируют состояние главного переключателя.
- Если изменить bind IP/порт работающего сервера и сохранить, сервер
  автоматически перезапускается для применения endpoint.
- Консоль сервера получила вертикальный скролл и автоматически показывает
  последние строки внизу.

Локализация:
- StorageChooser / файловый менеджер получил RU/EN подписи: выбор, создание,
  новая папка, отмена, внутренняя память, свободное место и сообщения ошибок.
- Локализованы сообщения подготовки запуска ArenaMP и ошибки запуска/создания
  папки настроек.

Нативная часть не менялась: libtes3mp.so, libarenamp_server.so и native dependencies
можно брать из предыдущего V1.4.x cache/build tree.
