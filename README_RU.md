# ArenaMP Android Y001 r1

Очищенный Android-сборщик ArenaMP для ветки Y001. По умолчанию используется `pporsilkde/AMP` `main`. Android-правки больше не привязаны к координатам строк unified diff: `anchor_patch.py` ищет реальный контекст кода и явные `ARENA_ANCHOR` там, где контекст неоднозначен.

Повторный запуск patch-stage безопасен: уже применённые изменения распознаются. Если после изменения `main` якорь исчез или стал неоднозначным, сборка останавливается, а не применяет patch приблизительно. Большие X056/X057 патчи, уже вошедшие в desktop main, повторно не накладываются.

Основная команда:

```bash
cd buildscripts
./build.sh --arch arm64 --ccache --release --client-server
```

Правила сопровождения патчей: `PATCHING.md`.
